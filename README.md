# Projeto Catálogo de Filmes

## 1. Objetivo

O projeto tem como objetivo criar um sistema para organizar uma coleção pessoal de filmes. O usuário poderá cadastrar seus filmes e adicionar informações como título, ano, gênero, nota e capa.

O sistema também permitirá visualizar, editar e excluir filmes cadastrados.



## 2. Requisitos Funcionais

**RF01 – Login**  
O sistema deve permitir que o usuário entre utilizando login e senha.

**RF02 – Cadastrar filme**  
O usuário deve poder cadastrar um novo filme.

**RF03 – Informações do filme**  
No cadastro, o usuário deve informar:

-   Título do filme;
    
-   Ano de lançamento;
    
-   Gênero;
    
-   Nota de 0 a 10;
    
-   Imagem da capa.
    

**RF04 – Visualizar filmes**  
O sistema deve apresentar todos os filmes cadastrados pelo usuário em uma galeria.

**RF05 – Editar filme**  
O usuário deve poder alterar as informações de um filme já cadastrado.

**RF06 – Alterar capa**  
O usuário deve poder trocar a imagem da capa de um filme.

**RF07 – Excluir filme**  
O usuário deve poder excluir um filme da sua coleção.

**RF08 – Confirmação de exclusão**  
O sistema deve pedir confirmação antes de excluir um filme.


## 3. Requisitos Não Funcionais

**RNF01 – Segurança**  
O sistema deve proteger os dados do usuário por meio de login e senha.

**RNF02 – Usabilidade**  
O sistema deve possuir uma interface simples e fácil de utilizar.

**RNF03 – Responsividade**  
O sistema deve funcionar corretamente em computadores, celulares e tablets.

**RNF04 – Desempenho**  
O sistema deve carregar as informações dos filmes de forma rápida.

**RNF05 – Armazenamento**  
Os dados cadastrados devem ser armazenados corretamente para que não sejam perdidos.

**RNF06 – Compatibilidade**  
O sistema deve funcionar nos principais navegadores, como Chrome, Edge e Firefox.


## 4. Regras de Negócio

-   A nota do filme deve estar entre **0 e 10**.
    
-   O usuário deve estar logado para acessar sua coleção.
    
-   O usuário só poderá alterar ou excluir seus próprios filmes.
    
-   Cada filme deve possuir um título.
    
-   A exclusão de um filme deve ser confirmada pelo usuário.
    



## 5. Funcionalidades Principais

O sistema terá como principais funcionalidades:

1.  Fazer login;
    
2.  Cadastrar filmes;
    
3.  Adicionar capa aos filmes;
    
4.  Visualizar a coleção;
    
5.  Editar informações;
    
6.  Alterar a capa;
    
7.  Excluir filmes.
    



## 6. Fora do Escopo

Nesta primeira versão, o sistema não terá:

-   Compartilhamento de filmes;
    
-   Comentários;
    
-   Avaliações de outros usuários;
    
-   Integração com redes sociais.
    

Essas funcionalidades poderão ser adicionadas futuramente.
